# Equal Sums / Одинаковые суммы

## Условие

Дан набор очков, полученных за выигранные партии. Нужно определить, можно ли разбить все очки на две части так, чтобы суммы в этих частях были равны.

## Формат ввода

Первая строка содержит число `n` — количество партий.

Вторая строка содержит `n` неотрицательных целых чисел — очки за партии.

## Формат вывода

Вывести `True`, если разбиение на две части с одинаковой суммой возможно.

Иначе вывести `False`.

## Ограничения

* `0 ≤ n ≤ 300`
* каждое число не превосходит `300`

## Примеры

| №   | Ввод             | Вывод   |
| --- | ---------------- | ------- |
| 1   | `4`<br>`1 5 7 1` | `True`  |
| 2   | `3`<br>`2 10 9`  | `False` |

-- ОПИСАНИЕ --
Реализовано определение возможности разбить все очки, набранные в выигранных
партиях, на две части с одинаковой суммой.

-- ПРИНЦИП РАБОТЫ --
1. Считывается массив очков, набранных в выигранных партиях
2. Если массив пуст, возвращаем True, т.к. пустое множество можно разбить
на две части с суммой 0 и 0
3. Считается общая сумма всех очков (total_sum)
4. Если total_sum нечетная, возвращается False, т.к. разделить ее на две
целые равные части невозможно
5. Вычисляется искомая сумма sum = total_sum/2, которую нужно получить из
подмножества очков
6. Создается массив dp из булевых значений размером sum + 1, где dp[s]
показывает, можно ли набрать сумму s из уже рассмотренных чисел
7. Начальное состояние dp[0] = true, т.к. сумму = 0 можно получить, не
выбирая ни одного числа
8. Далее, для каждого числа num из массива:
- Если num > sum, досрочно возвращаем False, т.к. если число больше
половины общей суммы, то разделить массив на две равные части невозможно
- Перебираем возможные суммы s от sum до num (справа налево) и обновляем:
dp[s] = dp[s] || dp[s - num]. Обход справа налево нужен, чтобы не
использовать одно и то же число более одного раза
- Если после обновления dp нашлась необходимая сумма (dp[sum] = true),
досрочно возвращаем True
9. Если после обработки всех чисел dp[sum] осталось false, возвращаем False

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Задача сводится к проверке, можно ли набрать половину общей суммы из
некоторого подмножества чисел. Если общая сумма нечетная, такое разбиение
невозможно.

Массив dp показывает, какие суммы можно получить из уже рассмотренных чисел:
dp[s] = true, если сумму s набрать можно. Переход dp[s] = dp[s] || dp[s - num]
учитывает два варианта - использовать текущее число или пропустить его, а
обход справа налево не позволяет использовать одно и то же число повторно.

Следовательно, dp[sum] = true тогда и только тогда, когда массив можно
разбить на две части с равной суммой.

-- СПИСОК ОБОЗНАЧЕНИЙ --
n - кол-во выигранных партий (от 0 до 300)
total_sum - общая сумма всех очков (максимум 300х300 = 90000)
sum - искомая сумма (половина от общей - total_sum/2)

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Считывание массива очков: O(n)
Вычисление общей суммы очков: O(n)
Перебор возможных сумм: O(n * sum)

ИТОГО: O(n * sum)

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
Хранение массива очков: O(n)
Массив возможных сумм: O(sum)

ИТОГО: O(n + sum)
