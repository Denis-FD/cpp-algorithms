# Levenshtein Distance / Расстояние Левенштейна

## Условие

Даны две строки `s` и `t`. Нужно найти минимальное количество операций, с помощью которых можно превратить строку `s` в строку `t`.

Доступные операции: удаление, вставка и замена символа.

## Формат ввода

Первая строка содержит строку `s`.

Вторая строка содержит строку `t`.

## Формат вывода

Вывести одно число — расстояние Левенштейна между строками.

## Ограничения

* длины обеих строк не превосходят `1000`
* строки состоят из строчных латинских букв

## Примеры

| №   | Ввод                           | Вывод |
| --- | ------------------------------ | ----- |
| 1   | `abacaba`<br>`abaabc`          | `2`   |
| 2   | `innokentiy`<br>`innnokkentia` | `3`   |
| 3   | `r`<br>`x`                     | `1`   |

-- ОПИСАНИЕ --
Реализовано нахождение расстояния Левенштейна для пары строк - минимального
кол-ва односимвольных операций (вставка/удаление/замена), необходимых для
превращения одной строки в другую.

-- ПРИНЦИП РАБОТЫ --
1. Считываются две строки (s, t) и передаются в ф-цию LevenshteinDistance(s, t).
2. Если t.size() > s.size(), строки меняются местами, чтобы уменьшить
размер массива dp и использовать O(min(n, m)) дополнительной памяти
1. Создается одномерный массив dp размером m + 1, где m - длина меньшей строки
2. Изначально dp[j] хранит расстояние от пустой строки до префикса строки t
длины j, поэтому dp[j] = j
1. Далее, последовательно обрабатываются символы строки s
2. Для каждой позиции i сохраняется значение prev_diag - прежнее значение
ячейки по диагонали, соответствующее dp[i - 1][j - 1] в двумерной записи
1. Для каждой позиции j вычисляются три варианта перехода: удаление - upper + 1,
вставка - left + 1, замена - prev_diag, если символы равны, иначе prev_diag + 1
1. В dp[j] записывается минимум из этих трех значений
2. После обработки всех символов строк ответ хранится в dp[m] - последней
ячейке массива.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Алгоритм Вагнера-Фишера реализует классическую рекуррентную формулу расстояния
Левенштейна (см. https://ru.wikipedia.org/wiki/Расстояние_Левенштейна):
D(i, j) = min(
    D(i-1, j) + 1,   // удаление
    D(i, j-1) + 1,   // вставка
    D(i-1, j-1) + cost  // замена (cost = 0 если символы равны, иначе 1)
)
с начальными условиями D(0, 0) = 0, D(0, j) = j, D(i, 0) = i.
Оптимизация с одной строкой dp корректна, т.к. для вычисления D(i, j)
нужны только D(i-1, j), D(i, j-1) и D(i-1, j-1), которые доступны через
переменные upper, left и prev_diag.

-- СПИСОК ОБОЗНАЧЕНИЙ --
s - первая строка
t - вторая строка
n - кол-во символов в строке s
m - кол-во символов в строке t

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Вычисление расстояния для всех пар символов двух строк: O(n * m)

ИТОГО: O(n * m)

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
Хранение двух строк: O(n + m)
Дополнительная память (массив dp): O(min(n, m))

ИТОГО: O(n + m)
