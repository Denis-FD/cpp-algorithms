# Expensive Network / Дорогая сеть

## Условие

Дан неориентированный взвешенный граф. Нужно найти вес максимального остовного дерева.

Если граф несвязный и остовное дерево построить невозможно, нужно вывести строку `Oops! I did it again`.

## Формат ввода

Первая строка содержит два числа `n` и `m` — количество вершин и рёбер графа.

Следующие `m` строк содержат тройки чисел `u`, `v`, `w`, где:

* `u` и `v` — вершины, соединённые ребром;
* `w` — вес ребра.

## Формат вывода

Если максимальное остовное дерево существует, вывести его вес.

Иначе вывести строку `Oops! I did it again`.

## Ограничения

* `1 ≤ n ≤ 1000`
* `0 ≤ m ≤ 100000`
* `1 ≤ u, v ≤ n`
* `0 ≤ w ≤ 10000`
* в графе могут быть петли и кратные рёбра
* граф может быть несвязным

## Примеры

| №   | Ввод                                              | Вывод                  |
| --- | ------------------------------------------------- | ---------------------- |
| 1   | `4 4`<br>`1 2 5`<br>`1 3 6`<br>`2 4 8`<br>`3 4 3` | `19`                   |
| 2   | `3 3`<br>`1 2 1`<br>`1 2 2`<br>`2 3 1`            | `3`                    |
| 3   | `2 0`                                             | `Oops! I did it again` |

-- ОПИСАНИЕ --
Реализовано нахождение веса максимального остовного дерева алгоритмом Прима
(см. https://ru.wikipedia.org/wiki/Алгоритм_Прима) с использованием приоритетной очереди
(на основе max-heap) для неориентированного взвешенного графа.

-- ПРИНЦИП РАБОТЫ --
1. Построение графа: из списка взвешенных ребер формируется список смежности для каждой вершины.
2. Создается массив посещенных вершин и приоритетная очередь (пара: вес, вершина)
3. Начинаем построение с 1-й вершины.
4. Наполняем приоритетную очередь соседними вершинами к стартовой
5. Далее, в цикле (пока очередь не пуста):
- извлекаем ребро максимального веса
- если вершина к которому оно относится уже посещена, пропускаем
- иначе прибавляем вес ребра к общему весу, отмечаем вершину как посещенную
- добавляем в очередь ребра, ведущие в непосещенные вершины
6. После обработки всех вершин в очереди проверяем, все ли вершины посещены:
если да - выводим сумму,
если нет - выводим строку "Oops! I did it again"

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Алгоритм Прима для максимального остовного дерева работает аналогично классическому,
но на каждом шаге выбирает не минимальное, а максимальное по весу ребро, соединяющее
построенную часть дерева с новой вершиной. Такое ребро не образует цикл, а значит
дерево строится корректно.
Если в конце посещены все вершины, построено максимальное остовное дерево, если нет -
граф несвязен, соответственно, максимальное остовное дерево не существует.

-- СПИСОК ОБОЗНАЧЕНИЙ --
n - кол-во вершин
m - кол-во ребер

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Построение графа (список смежности): O(m).
Построение остовного дерева: O(m log m) - каждое ребро добавляется и извлекается
из очереди не более одного раза, операции с которой выполняются за O(log m).

ИТОГО: O(m log m)

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
Хранение графа: O(n + m)
Массив посещенных вершин: O(n)
Приоритетная очередь: в худшем случае содержит все ребра - O(m)

ИТОГО: O(n + m)
