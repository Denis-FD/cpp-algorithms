# Water World / Водный мир

## Условие

Дана карта размером `n × m`, состоящая из клеток земли `#` и воды `.`. Нужно найти количество островов и размер самого большого острова.

Островом считается группа клеток земли, соединённых по горизонтали или вертикали. Клетки, соприкасающиеся только по диагонали, относятся к разным островам.

## Формат ввода

Первая строка содержит два числа `n` и `m` — размеры карты.

Далее идут `n` строк по `m` символов в каждой:

* `#` — земля;
* `.` — вода.

## Формат вывода

Вывести два числа:

* количество островов;
* размер самого большого острова.

## Ограничения

* `1 ≤ n, m ≤ 1000`
* карта непустая
* клетки карты содержат только символы `#` и `.`

## Примеры

| №   | Ввод                                              | Вывод |
| --- | ------------------------------------------------- | ----- |
| 1   | `3 3`<br>`#.#`<br>`.#.`<br>`#.#`                  | `5 1` |
| 2   | `4 5`<br>`#####`<br>`.#...`<br>`..#..`<br>`#####` | `2 6` |

```txt
-- ОПИСАНИЕ --
Реализован поиск количества островов и размера самого большого острова
на карте из земли и воды с помощью обхода в ширину (BFS).
Карта рассматривается как граф, где каждая клетка поля - вершина,
а ребра существуют только между соседними по стороне клетками земли.

-- ПРИНЦИП РАБОТЫ --
1. Из ввода считывается поле размера n на m в переменную field,
где '#' - земля, '.' - вода.
1. Далее выполняется проход по всем клеткам поля от {0,0} до {n-1,m-1}
2. Если текущая клетка является землей, значит найдена новая часть суши
(новый остров). Увеличивается счетчик островов и запускается BFS из
этой клетки.
1. Алгоритм BFS из стартовой клетки обходит весь текущий остров,
достижимый по вертикали и горизонтали. Выход за границы поля и вода
отбрасываются. Просмотренные клетки земли сразу помечаются в field
как вода, добавляются в очередь и учитываются в размере острова.
1. После завершения BFS получаем размер текущего острова и обновляем
максимальный размер среди найденных.
1. После обработки всех клеток поля выводится результат.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Каждый остров является компонентой связности графа, где вершины - клетки
земли, а ребра соединяют соседние по горизонтали или вертикали клетки.
BFS, запущенный из клетки земли, полностью обходит весь текущий остров и
сразу помечает все его клетки как обработанные прямо в field, что гарантирует
однократный учет каждого острова и корректное вычисление его размера.

-- СПИСОК ОБОЗНАЧЕНИЙ --
n - кол-во строк поля
m - кол-во столбцов поля

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Считывание поля: O(n * m)
Внешний проход по всем клеткам: O(n * m)
Все запуски BFS суммарно: O(n * m), т.к. каждая клетка попадает в очередь
и обрабатывается не более одного раза

ИТОГО: O(n * m)

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
Хранение поля: O(n * m)
Очередь BFS: в худшем случае O(n * m)

ИТОГО: O(n * m)
```
