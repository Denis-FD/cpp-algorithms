# Broken Search / Поиск в сломанном массиве

## Условие

Дан отсортированный массив уникальных чисел, который мог быть циклически сдвинут. Нужно найти индекс заданного элемента за `O(log n)`.

Если элемент не найден, нужно вернуть `-1`.

## Формат ввода

Функция принимает массив натуральных чисел и искомое число `k`.

В примерах формат такой:

* первая строка содержит число `n`;
* вторая строка содержит число `k`;
* третья строка содержит `n` элементов массива.

## Формат вывода

Функция должна вернуть индекс элемента, равного `k`, или `-1`, если такого элемента нет.

## Ограничения

* длина массива не превосходит `10000`
* элементы массива уникальны
* элементы массива и число `k` не превосходят `10000`
* изменять массив нельзя
* решение должно работать за `O(log n)`

## Примеры

| №   | Ввод                                     | Вывод |
| --- | ---------------------------------------- | ----- |
| 1   | `9`<br>`5`<br>`19 21 100 101 1 4 5 7 12` | `6`   |
| 2   | `2`<br>`1`<br>`5 1`                      | `1`   |

```txt
-- ОПИСАНИЕ --
Реализован поиск индекса элемента в сдвинутом отсортированном массиве за временную сложность O(log N)
метод int broken_search(const std::vector<int>& vec, int k)
возвращает индекс искомого элемента или "-1" если элемент не найден или вектор пуст, где:
std::vector<int> vec - элементы массива,
int k - искомое значение.

-- ПРИНЦИП РАБОТЫ --
- берем крайний левый (left) и крайний правый (right) индексы массива и находим центральный (mid)
- если значение в середине равно искомому возвращаем индекс, если нет, то:
- ищем в какой половине массива продолжить поиск в левой или правой, для этого
- заводим булеву переменную move_right (если true - искать справа, т.е. интервал mid-right
или, если false - искать слева, т.е. интервал left-mid)
- далее определяем какая из сторон отсортирована (vec[left] <= vec[mid]) - если значение
слева меньше или равно значению посередине, значит левая часть отсортирована, а если она отсортирована,
мы можем узнать находится ли в этом интервале искомое значение k сравнив его с ними.
Соответственно, если левая часть не отсортирована, значит отсортирована правая, в этом случае,
проверяем, входит ли k в правую часть.
- После того, как мы выяснили в какую сторону продолжить поиск move_right, мы сдвигаем левый или правый индексы,
при этом центральный исключаем, т.к. мы уже проверили равен он искомому или нет.
- Далее, алгоритм будет продолжаться пока диапазон поиска не пуст (left <= right).
- Если элемент не будет найден вернется -1.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Поддерживается инвариант: если k есть в массиве, то оно всегда лежит в диапазоне left-right.
На каждой итерации проверяется значение в mid, если vec[mid] != k, определяется отсортированная половина,
в которой проверяется, может ли k находится в ней, и соответственно, отбрасывается часть, где k быть не может.
Диапазон поиска каждый раз уменьшается, пока не станет пустым, значит алгоритм либо находит k,
либо возвращает -1.

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Т.к. каждая итерация в цикле делит массив по полам временная сложность O(log N), где N - кол-во элементов в массиве.

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
O(1) - используются O(1) вспомогательные переменные.
```
