# Word Break / Шпаргалка

## Условие

Дан текст без пробелов и словарь допустимых слов. Нужно определить, можно ли разбить текст на последовательность слов из словаря. Слова можно использовать несколько раз и в любом порядке.

## Формат ввода

Первая строка содержит текст `T`.
Вторая строка содержит число `n`.
Следующие `n` строк содержат слова словаря.

## Формат вывода

Вывести `YES`, если текст можно разбить на слова из словаря, иначе вывести `NO`.

## Ограничения

- `|T| ≤ 100100`
- `1 ≤ n ≤ 100`
- длина каждого слова не превосходит `100`
- все строки состоят из строчных английских букв

## Примеры

| №   | Ввод                                                                        | Вывод |
| --- | --------------------------------------------------------------------------- | ----- |
| 1   | `examiwillpasstheexam`<br>`5`<br>`will`<br>`pass`<br>`the`<br>`exam`<br>`i` | `YES` |
| 2   | `abacaba`<br>`2`<br>`abac`<br>`caba`                                        | `NO`  |
| 3   | `abacaba`<br>`3`<br>`abac`<br>`caba`<br>`aba`                               | `YES` |

```txt
-- ОПИСАНИЕ --
Реализовано определение возможности разбить текст на слова из
заданного словаря (набора слов).

-- ПРИНЦИП РАБОТЫ --
1. Считывается текст T и набор слов словаря, по которым строится
префиксное дерево (бор), позволяющее быстро определять, какие слова
могут начинаться с каждой позиции текста.

2. Принцип построения префиксного дерева (класс Trie):
- в качестве узла (Node) выбран массив (array) переходов длины 26
по количеству строчных букв английского алфавита;
- изначально trie создается с корневым нулевым узлом;
- при создании узла все переходы заполняются значением -1, которое
означает отсутствие перехода;
- при добавлении слова в бор индекс буквы вычисляется как ch - 'a';
- при отсутствии перехода создается новый узел и его индекс
записывается в nodes_, если переход есть - выполняется переход дальше;
- узел, соответствующий последнему символу слова, отмечается как
терминальный.

3. Публичные методы класса Trie:
- Add(word) — добавляет слово в префиксное дерево;
- GetRoot() — возвращает индекс корневого узла (0);
- Next(node, ch) — возвращает индекс следующего узла по символу
ch (-1 если перехода нет);
- IsTerminal(node) — проверяет, является ли узел терминальным.

4. После заполнения префиксного дерева создается массив dp из булевых
значений размера длина текста + 1 для определения возможности разбить
текст на слова методом динамического программирования.

5. Стартовое значение: dp[0] = true, т.к. пустой префикс всегда
можно разбить корректно.
6. Далее, во внешнем цикле перебираются все позиции текста.
7. Если dp[start] == false, т.е. до этой позиции текст разбить нельзя,
выполняется переход к следующей позиции.
8. Из корневого узла префиксного дерева начинаем перебирать символы текста,
начиная с текущей позиции. Если перехода нет, выходим из цикла.
Если переход есть и текущий узел терминальный, отмечаем достижимость
соответствующей позиции в массиве dp.
9. Если последняя позиция текста достижима из набора слов, значит текст
можно разбить на слова из словаря, возвращается true и выводится YES.
10.  Если после обработки всех символов текста последняя позиция так и не
стала достижимой, возвращается false и выводится NO.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Префиксное дерево (бор) строится корректно: каждое слово из словаря
добавляется посимвольно, при необходимости создаются новые узлы,
а узел последнего символа помечается терминальным. Поэтому для любой
позиции текста переходами по бору можно проверить все слова словаря,
которые начинаются в этой позиции, и точно определить, оканчивается ли
в текущем узле какое-либо слово.

Массив dp хранит достижимость позиций текста: dp[i] = true, если первые
i символов можно разбить на слова из словаря. Значение dp[0] = true, т.к.
пустой префикс уже разбит корректно. Если dp[start] = true, то из позиции
start с помощью бора перебираются все слова словаря, которые могут там
начинаться, и позиция после конца каждого такого слова помечается достижимой.
Значит, если dp[text.size()] = true, то весь текст можно разбить на слова из словаря.

-- СПИСОК ОБОЗНАЧЕНИЙ --
T — текст
m — длина текста T (m ≤ 100100)
n — кол-во слов в словаре (1 ≤ n ≤ 100)
M — максимальная длина слова в словаре (M ≤ 100)
L — суммарная длина всех слов словаря
k — размер алфавита (k = 26)

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Считывание текста: O(m)
Считывание слов: O(L)
Построение префиксного дерева: O(L)
Поиск допустимых переходов (динамическое программирование):
- внешний цикл по тексту: O(m)
- из каждой достижимой позиции выполняется проход по бору
не более чем на M символов, каждый переход выполняется за O(1),
следовательно - O(m * M)

ИТОГО: O(L + m * M)

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
Хранение текста: O(m)
Хранение префиксного дерева: O(L * k), т.к. в каждом из O(L) узлов
хранится массив переходов размера k. Поскольку k = 26 - константа,
итоговая сложность - O(L).
Массив dp: O(m)

ИТОГО: O(m + L)
```
