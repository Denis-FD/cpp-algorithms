# Packed Prefix / Упакованный префикс

## Условие

Даны строки в запакованном виде. Нужно распаковать их и найти наибольший общий префикс всех распакованных строк.

Запакованная строка может содержать строчные английские буквы, конкатенацию строк и конструкции вида `n[A]`, где `n` — однозначное натуральное число, а `A` — корректная запакованная строка. Такая запись означает повтор строки `A` ровно `n` раз.

## Формат ввода

Первая строка содержит число `n` — количество строк.

Следующие `n` строк содержат корректные запакованные строки.

## Формат вывода

Вывести наибольший общий префикс распакованных строк.

## Ограничения

* `1 ≤ n ≤ 1000`
* строки состоят из строчных английских букв, цифр и квадратных скобок
* все запакованные строки корректны
* длина каждой строки после распаковки не превосходит `10^5`

## Примеры

| №   | Ввод                                                 | Вывод |
| --- | ---------------------------------------------------- | ----- |
| 1   | `3`<br>`2[a]2[ab]`<br>`3[a]2[r2[t]]`<br>`a2[aa3[b]]` | `aaa` |
| 2   | `3`<br>`abacabaca`<br>`2[abac]a`<br>`3[aba]`         | `aba` |

-- ОПИСАНИЕ --
Реализован поиск наибольшего общего префикса распакованных строк.

-- ПРИНЦИП РАБОТЫ --
1. Считывается и распаковывается первая строка, которая принимается
за текущий наибольший общий префикс (lcp - longest common prefix).
2. Принцип распаковки строки:
- резервируется буферная строка (s) размером до 10^5 символов;
- в нее поочередно добавляются символы запакованной строки, пока не
встретится символ ']';
- если встретился символ ']', создается временная строка (block),
в которую в обратном порядке добавляются символы из конца строки s,
пока не встретится символ '[';
- далее символ '[' удаляется, строка block переворачивается,
считывается количество повторов (k), удаляется эта цифра и в строку s
block добавляется k раз;
- после обработки всей запакованной строки в s находится ее
полностью распакованный вид.
3. Далее, считываются оставшиеся n-1 строк, каждая из них
распаковывается и сравнивается с текущим префиксом lcp.
4. Для двух строк выбирается минимальная длина, после чего строки
посимвольно сравниваются с первого символа до первого различия
или до конца более короткой строки.
5. После сравнения строка lcp обрезается до совпавшей части,
т.е. до текущего общего префикса двух строк.
6. После обработки всех n строк в lcp остается наибольший
общий префикс всех распакованных строк.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
При распаковке строка s используется как стек. Обычные символы
добавляются в конец, а при встрече ']' из конца извлекается
ближайший блок до '[', после чего он повторяется k раз.
Т.к. внутренние  блоки раскрываются раньше внешних, после
обработки всей строки в s получается ее распакованный вид.

Изначально lcp равен первой распакованной строке. Затем, для каждой
следующей строки он обрезается до общей совпадающей начальной части,
поэтому всегда остается общим префиксом всех обработанных строк.
После обработки всех строк в lcp остается наибольший общий префикс.

-- СПИСОК ОБОЗНАЧЕНИЙ --
n — кол-во строк (1 ≤ n ≤ 1000)
M — максимальная длина строки в распакованном виде (M ≤ 10^5)

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Считывание одной строки: O(M)
Распаковка одной строки: O(M), т.к. каждый символ обрабатывается
константное число раз
Поиск общего префикса двух строк: O(M)
Все перечисленные операции выполняются для каждой из n строк.

ИТОГО: O(n * M)

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
Текущий общий префикс: O(M)
Текущая распакованная строка: O(M)
Вспомогательный буфер при распаковке: O(M)

ИТОГО: O(M)
