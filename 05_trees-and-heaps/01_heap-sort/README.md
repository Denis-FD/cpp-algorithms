# Heap Sort / Пирамидальная сортировка

## Условие

Дан список участников: логин, число решенных задач и штраф. Нужно отсортировать таблицу результатов по приоритетам: больше задач, меньше штраф, лексикографически меньший логин.

Кучу необходимо реализовать самостоятельно.

## Формат ввода

Первая строка содержит число `n`.

Далее идут `n` строк формата `login solved penalty`, где `login` — уникальный логин, `solved` — число решенных задач, `penalty` — штраф.

## Формат вывода

Вывести логины участников в отсортированном порядке, по одному логину в строке.

## Ограничения

* `1 ≤ n ≤ 100000`
* длина логина не превосходит `20`
* логины состоят из строчных латинских букв
* все логины уникальны
* `0 ≤ solved ≤ 10^9`
* `0 ≤ penalty ≤ 10^9`
* кучу необходимо реализовать самостоятельно

-- ОПИСАНИЕ --
Реализована сортировка списка участников олимпиады по трем ключам:
- score - по убыванию,
- penalty - по возрастанию (при равных score),
- name - по алфавиту (лексикографически, при равных score и penalty).

-- ПРИНЦИП РАБОТЫ --
Для сортировки участников используется пирамидальная сортировка (HeapSort) на основе min-heap:

1. Построение кучи (BuildHeap):
Создается копия исходного массива, из которой формируется куча путем просеивания вниз (SiftDown)
всех внутренних узлов - от последнего (n/2 - 1) до корневого включительно.

1. Извлечение элементов:
Из кучи, последовательно извлекаются минимальные элементы (PopMin) и
записываются обратно в исходный массив. Функция SiftDown опускает корневой элемент вниз,
восстанавливая свойство кучи после каждого извлечения.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Функция SiftDown корректно поддерживает свойство кучи:
- При построении кучи (BuildHeap) SiftDown применяется ко всем внутренним узлам,
обеспечивая выполнение свойства min-heap для каждого поддерева
- При удалении корень заменяется последним элементом, который опускается вниз (SiftDown),
восстанавливая свойства кучи

-- СПИСОК ОБОЗНАЧЕНИЙ --
n - количество участников олимпиады

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Построение кучи: O(n) - просеивание всех внутренних узлов от (n/2 - 1) до корня
Извлечение элементов: O(n log n) - каждый из n элементов извлекается за O(log n)
ИТОГО: O(n log n)

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
O(n) - дополнительная память для хранения кучи
