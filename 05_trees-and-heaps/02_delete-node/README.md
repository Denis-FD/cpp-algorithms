# Delete Node / Удали узел

## Условие

Дано бинарное дерево поиска с уникальными целочисленными ключами. Нужно найти вершину с заданным ключом и удалить её так, чтобы дерево осталось корректным бинарным деревом поиска.

Если ключа в дереве нет, изменять дерево не нужно.

Создавать новые вершины нельзя.

## Формат ввода

На вход функции подаются:

* корень бинарного дерева поиска;
* ключ, который нужно удалить.

## Формат вывода

Функция должна вернуть корень изменённого дерева.

## Ограничения

* ключи дерева — натуральные числа, не превышающие `10^9`;
* все ключи уникальны;
* новые вершины создавать нельзя;
* сложность удаления должна быть `O(h)`, где `h` — высота дерева.

<summary>Подробное описание</summary>

```txt
-- ОПИСАНИЕ --
Реализована ф-ция удаления узла с заданным ключом из бинарного дерева поиска (BST).

-- ПРИНЦИП РАБОТЫ --
Рекурсивно ищем ключ, двигаясь влево/вправо по правилам BST. Если вершины
с таким ключом нет, ф-ция возвращает исходный корень, дерево не модифицируется.

После того как ключ найден, удаление найденного узла сводится к 4 случаям:
1. Нет детей: узел просто удаляется, родителю возвращается nullptr
2-3. Только один ребенок справа или слева: ребенок занимает место удаленного
узла (родитель теперь ссылается на ребенка)
1. Два ребенка:
- Находится минимальный узел в правом поддереве (самый левый)
- Копируется его значение в удаляемый узел
- Рекурсивно удаляется этот минимальный узел из правого поддерева

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Свойства бинарного дерева поиска сохраняются после удаления:
1. Нет детей: удаление листа не нарушает порядок
2-3. Один ребенок: поддерево ребенка сохраняет порядок относительно родителей
4. Два ребенка: минимальный элемент правого поддерева гарантированно больше всех
элементов левого поддерева и меньше всех остальных элементов правого поддерева

-- СПИСОК ОБОЗНАЧЕНИЙ --
n - кол-во вершин (ключей) в дереве
h - высота дерева
(в сбалансированном дереве h ~ log n, в худшем случае h ~ n)

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Поиск узла - O(h), поиск минимума в правом поддереве - O(h), удаление - O(h).
Итого: O(h)

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
O(h) на стек вызовов (глубина рекурсии не превышает высоту дерева)
```
