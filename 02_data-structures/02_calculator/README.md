# Calculator / Калькулятор

## Условие

Дано арифметическое выражение в обратной польской нотации. Нужно вычислить его значение с помощью стека.

Поддерживаются операции `+`, `-`, `*`, `/`. Деление целочисленное, с округлением вниз.

## Формат ввода

Единственная строка содержит выражение в обратной польской нотации.

Числа и операции разделены пробелами.

## Формат вывода

Вывести одно число — значение выражения.

## Ограничения

* числа по модулю не превосходят `10000`
* промежуточные значения по модулю не превосходят `50000`
* поддерживаемые операции: `+`, `-`, `*`, `/`
* деления на отрицательное число нет

## Примеры

| №   | Ввод            | Вывод |
| --- | --------------- | ----- |
| 1   | `2 1 + 3 *`     | `9`   |
| 2   | `7 2 + 4 * 2 +` | `38`  |

<summary>Подробное описание</summary>

```txt
-- ОПИСАНИЕ --
Вычисление выражения в обратной польской нотации (ОПН) с помощью стека.

Переменные:
std::stack<int> numbers - числа (операнды)

-- ПРИНЦИП РАБОТЫ --
Читается входная строка, разделяется на токены по пробелам.
Если токен число - кладется в стек, если операция, вынимается 2 верхних числа,
производится операция - результат записывается обратно в стек.
Для деления используется отдельный метод FloorDiv - математическое целочисленное деление (округление вниз)
При a % b < 0 (т.е. когда деление не нацело и остаток отрицательный) - частное уменьшается на 1.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Числа кладутся в стек, а операция вынимает два верхних числа со стека и заменяет их результатом
операции (+, -, *, /). Соответственно, стек всегда хранит текущие промежуточные результаты,
как и требуется в ОПН. Значит после чтения всей строки на вершине стека находится ответ.

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
O(N), где N - число токенов во входной строке: каждый токен обрабатывается за O(1).

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
O(N), где N - число токенов во входной строке: в худшем случае стек содержит O(N) чисел
(операндов/промежуточных результатов), остальное - O(1).
```
