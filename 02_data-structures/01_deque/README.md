# Deque / Дек

## Условие

Нужно реализовать дек фиксированного размера на кольцевом буфере.

Дек должен поддерживать операции добавления и удаления элементов с обеих сторон за `O(1)`.

## Формат ввода

Первая строка содержит число `n` — количество команд.

Вторая строка содержит число `m` — максимальный размер дека.

Следующие `n` строк содержат команды:

* `push_back value`
* `push_front value`
* `pop_back`
* `pop_front`

## Формат вывода

Для команд `pop_back` и `pop_front` вывести удалённый элемент.

Если операция невозможна, вывести `error`.

Для успешных команд `push_back` и `push_front` ничего выводить не нужно.

## Ограничения

* `n ≤ 100000`
* `m ≤ 50000`
* `|value| ≤ 1000`
* все операции должны выполняться за `O(1)`
* реализация должна использовать кольцевой буфер

```txt
-- ОПИСАНИЕ --
Двусторонняя очередь (дек) фиксированного размера на кольцевом буфере.

Переменные:
std::vector<int> deque_ - элементы дека,
int max_n_ - вместимость дека,
int size_ - текущее количество элементов,
int head_ - индекс первого элемента,
int tail_ - индекс первой свободной позиции после последнего элемента.

-- ПРИНЦИП РАБОТЫ --
Используется кольцевой буфер deque_ размера max_n_.
Индексы head_ и tail_ изменяются по модулю max_n_ (через функции Next/Prev),
size_ хранит текущее количество элементов.

Операции:
PushBack(value) - записать value в позицию tail_, затем сдвинуть tail_ вперёд и увеличить size_,
PushFront(value) - сдвинуть head_ назад, записать value в новый head_ и увеличить size_,
PopFront() - прочитать элемент по head_, сдвинуть head_ вперёд и уменьшить size_,
PopBack() - сдвинуть tail_ назад, прочитать элемент по новому tail_ и уменьшить size_.

Если дек переполнен, операции PushBack/PushFront возвращают false.
Если дек пуст, операции PopFront/PopBack() возвращают std::nullopt.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --
Инварианты:
1) size_ - количество элементов в деке: от 0 до max_n_,
2) При size_ > 0 head_ указывает на первый элемент, а последний расположен по индексу Prev(tail_),
3) head_ и tail_ всегда лежат в диапазоне [0, max_n_ - 1], так как обновляются по модулю max_n_.

Каждая операция сдвигает только соответствующий индекс (head_ или tail_) на один шаг по кольцу и корректно
обновляет size_, поэтому инварианты сохраняются после любой команды.

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --
Каждая операция Push/Pop выполняется за O(1), поэтому обработка n команд занимает O(n),
где n - число команд из ввода.

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --
Хранится буфер на m элементов, где m — вместимость дека из ввода, и O(1) вспомогательных переменных.
Итого: O(m)
```
