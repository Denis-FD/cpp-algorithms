# Nearest Zero / Ближайший ноль

## Условие

Дан массив неотрицательных чисел с хотя бы одним `0`. Нужно для каждой позиции найти минимальное расстояние до позиции с нулем.

Расстояние между двумя позициями равно модулю разности их индексов.

## Формат ввода

Первая строка содержит число `n`.

Вторая строка содержит `n` неотрицательных чисел.

## Формат вывода

Вывести `n` чисел — минимальные расстояния от каждой позиции до ближайшего нуля.

## Ограничения

* `1 ≤ n ≤ 10^6`
* в массиве есть хотя бы один `0`
* положительные числа уникальны
* значения элементов не превосходят `10^9`

## Примеры

| №   | Ввод                  | Вывод         |
| --- | --------------------- | ------------- |
| 1   | `5`<br>`0 1 4 9 0`    | `0 1 2 1 0`   |
| 2   | `6`<br>`0 7 9 4 8 20` | `0 1 2 3 4 5` |

-- ОПИСАНИЕ --

Реализован поиск расстояния от каждого элемента массива до ближайшего нуля.

Для этого выполняются два прохода по массиву: слева направо и справа налево.

-- ПРИНЦИП РАБОТЫ --

1. Создаётся массив `res`, в котором будут храниться расстояния до ближайшего нуля.

2. Первый проход выполняется слева направо.

3. Переменная `zero_idx` хранит индекс последнего найденного нуля слева.

4. Если текущий элемент равен `0`, то `zero_idx` обновляется, а расстояние для текущей позиции равно `0`.

5. Если текущий элемент не равен `0`, то в `res[i]` записывается расстояние до ближайшего нуля слева.

6. Второй проход выполняется справа налево.

7. Переменная `zero_idx` теперь хранит индекс ближайшего найденного нуля справа.

8. Если текущий элемент равен `0`, то `zero_idx` обновляется.

9. Если текущий элемент не равен `0`, то текущее значение `res[i]` сравнивается с расстоянием до ближайшего нуля справа, и выбирается минимум.

10. После двух проходов в `res` для каждой позиции хранится расстояние до ближайшего нуля.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --

После первого прохода для каждой позиции известно расстояние до ближайшего нуля слева. Если нуля слева нет, значение расстояния получается заведомо большим.

После второго прохода для каждой позиции дополнительно рассматривается ближайший ноль справа. Для каждой позиции выбирается минимум из двух расстояний: до ближайшего нуля слева и до ближайшего нуля справа.

Ближайший ноль для любой позиции может находиться только слева, справа или в самой позиции. Поэтому после двух проходов для каждого элемента найдено корректное минимальное расстояние до ближайшего нуля.

-- СПИСОК ОБОЗНАЧЕНИЙ --

`n` — количество элементов массива.

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --

Первый проход по массиву занимает `O(n)`.

Второй проход по массиву занимает `O(n)`.

Итого: `O(n)`.

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --

Дополнительно хранится массив ответов `res` размера `n`.

Итого: `O(n)`
