# Game Points / Ловкость рук

## Условие

Дано поле `4 × 4`, состоящее из цифр от `1` до `9` и точек. Для каждой цифры нужно определить, смогут ли два игрока одновременно нажать все клетки с этой цифрой.

Каждый игрок может нажать не более `k` клавиш, значит вместе они могут нажать не более `2 * k` клавиш.

Бал начисляется за цифру, если она встречается на поле хотя бы один раз и количество ее вхождений не превосходит `2 * k`.

## Формат ввода

Первая строка содержит число `k`.

Следующие `4` строки содержат поле по `4` символа в каждой строке.

## Формат вывода

Вывести одно число — максимальное количество баллов.

## Ограничения

* `1 ≤ k ≤ 5`
* поле имеет размер `4 × 4`
* каждая клетка содержит точку `.` или цифру от `1` до `9`

## Примеры

| №   | Ввод                                        | Вывод |
| --- | ------------------------------------------- | ----- |
| 1   | `3`<br>`1231`<br>`2..2`<br>`2..2`<br>`2..2` | `2`   |
| 2   | `4`<br>`1111`<br>`9999`<br>`1111`<br>`9911` | `1`   |
| 3   | `4`<br>`1111`<br>`1111`<br>`1111`<br>`1111` | `0`   |

<summary>Подробное описание</summary>

-- ОПИСАНИЕ --

Реализован подсчет количества цифр, которые два игрока смогут нажать одновременно.

Для каждой цифры от `1` до `9` считается количество её появлений на поле. Если цифра встречается хотя бы один раз и количество её появлений не превышает `2 * k`, за неё начисляется один балл.

-- ПРИНЦИП РАБОТЫ --

1. Считывается число `k`.

2. Создаётся массив `buckets` размера `9`, где `buckets[i]` хранит количество появлений цифры `i + 1`.

3. Поле `4 × 4` считывается посимвольно.

4. Если символ не равен `.`, он преобразуется в цифру, и соответствующий счётчик увеличивается.

5. Вычисляется максимальное количество клавиш, которое могут нажать два игрока: `max_pushes = 2 * k`.

6. Далее перебираются цифры от `1` до `9`.

7. Если цифра встречается на поле и количество её появлений не превышает `max_pushes`, увеличивается ответ.

8. После проверки всех цифр выводится количество набранных баллов.

-- ДОКАЗАТЕЛЬСТВО КОРРЕКТНОСТИ --

Для каждой цифры от `1` до `9` массив `buckets` хранит точное количество её появлений на поле, так как каждая клетка поля обрабатывается ровно один раз.

Два игрока вместе могут нажать не более `2 * k` клавиш. Поэтому балл за цифру можно получить тогда и только тогда, когда количество клеток с этой цифрой больше нуля и не превосходит `2 * k`.

Алгоритм проверяет это условие для каждой цифры и увеличивает ответ только в случае его выполнения. Следовательно, итоговый ответ равен максимальному количеству баллов.

-- СПИСОК ОБОЗНАЧЕНИЙ --

`k` — количество клавиш, которое может нажать один игрок
`max_pushes` — количество клавиш, которое могут нажать два игрока вместе

-- ВРЕМЕННАЯ СЛОЖНОСТЬ --

Поле содержит фиксированные `16` клеток, а количество возможных цифр равно `9`.

Итого: `O(1)`.

-- ПРОСТРАНСТВЕННАЯ СЛОЖНОСТЬ --

Используется массив счетчиков фиксированного размера `9`.

Итого: `O(1)`.
